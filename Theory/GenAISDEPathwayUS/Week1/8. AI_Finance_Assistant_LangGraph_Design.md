# AI Finance Assistant - Multi-Agent LangGraph Architecture

## Project Overview

**Project Name:** Democratizing Financial Literacy Through Intelligent Conversational AI

**Description:** A production-ready multi-agent system that provides personalized, accessible financial education and guidance through an intelligent conversational interface. The system democratizes financial knowledge for beginners who are intimidated by traditional financial services.

**Key Objectives:**
- Enable natural conversation about financial topics
- Provide personalized financial guidance
- Real-time market data integration
- Portfolio analysis and recommendations
- Financial goal planning
- Tax and investment education
- News synthesis with financial context

## Agent Specifications

**Purpose:** Handles general financial education queries about concepts, strategies, and fundamentals.

**Inputs:**
- User query (string)
- Financial knowledge base (vector store)
- Conversation history
- User experience level (beginner/intermediate/advanced)

**Outputs:**
- Comprehensive answer
- Educational explanation level
- Source references
- Related topics
- Follow-up suggestions

**Behavior:**
- Uses RAG to retrieve relevant educational content
- Simplifies jargon for beginners
- Provides citations and sources
- Offers progressive complexity options
- Asks clarifying questions if needed

### Agent 7: Intent Router Agent (Orchestration)
**Purpose:** Routes user queries to appropriate agents based on intent detection.

**Inputs:**

- Confidence threshold

**Outputs:**
- Detected intent
- Selected agent(s)

**Behavior:**
- Analyzes query for intent

- Assigns confidence scores

**Inputs:**

- Generates targeted questions
- Waits for user clarification

**Inputs:**

**Outputs:**
- Synthesized results
- Conflict resolution

**Behavior:**
- Manages agent dependencies
- Executes in parallel when possible
- Resolves conflicting recommendations
- Synthesizes final output

## State TypedDict Definition

```python
from typing import TypedDict, Optional, List, Dict, Any
from datetime import datetime

class AgentThought(TypedDict):
    """Individual agent thinking/analysis"""
    agent_name: str
    thought_process: str
    confidence: float
    reasoning: str

class FinanceState(TypedDict):
    """Complete state for Finance Assistant LangGraph"""
    # Input
    user_query: str
    conversation_history: List[Dict[str, str]]
    user_id: str
    session_id: str
    
    # User Profile
    experience_level: str  # "beginner", "intermediate", "advanced"
    risk_tolerance: str    # "conservative", "moderate", "aggressive"
    financial_goals: List[str]
    portfolio_data: Optional[Dict[str, Any]]
    
    # Routing & Intent
    detected_intent: str  # Type of request (education, analysis, planning, etc.)
    selected_agents: List[str]  # Agents to execute
    confidence_scores: Dict[str, float]
    
    # Agent Outputs
    agent_thoughts: List[AgentThought]  # Thinking process from each agent
    agent_results: Dict[str, Any]  # Results from each agent
    
    # Market Data
    market_data: Optional[Dict[str, Any]]  # Real-time market info
    data_timestamp: Optional[datetime]
    
    # Knowledge Base
    knowledge_base_results: List[Dict[str, Any]]
    
    # Final Output
    final_response: str
    follow_up_suggestions: List[str]
    sources_cited: List[str]
    
    # Metadata
    execution_path: List[str]  # Track which nodes were executed
    error_messages: List[str]
    fallback_triggered: bool
    total_tokens_used: int
```

## State Transitions and Conditional Routing

```python
from langgraph.graph import StateGraph, END
from langgraph.types import Send

def create_finance_graph():
    graph = StateGraph(FinanceState)
    
    # Add nodes
    graph.add_node("intent_router", intent_router)
    graph.add_node("clarification", clarification_node)
    graph.add_node("finance_qa", finance_qa_agent)
    graph.add_node("portfolio_analysis", portfolio_analysis_agent)
    graph.add_node("market_analysis", market_analysis_agent)
    graph.add_node("goal_planning", goal_planning_agent)
    graph.add_node("news_synthesis", news_synthesizer_agent)
    graph.add_node("tax_education", tax_education_agent)
    graph.add_node("multi_agent", multi_agent_coordinator)
    graph.add_node("format_response", response_formatter)
    graph.add_node("error_handler", error_handler)
    
    # Entry point
    graph.set_entry_point("intent_router")
    
    # Conditional routing from intent_router
    def route_intent(state: FinanceState) -> str:
        if state['confidence_scores'].get('intent', 0) < 0.5:
            return "clarification"
        
        intent = state['detected_intent']
        if intent == 'education':
            return "finance_qa"
        elif intent == 'portfolio_analysis':
            return "portfolio_analysis"
        elif intent == 'market_info':
            return "market_analysis"
        elif intent == 'goal_planning':
            return "goal_planning"
        elif intent == 'news_synthesis':
            return "news_synthesis"
        elif intent == 'tax_info':
            return "tax_education"
        elif intent == 'multi_agent':
            return "multi_agent"
        else:
            return "error_handler"
    
    graph.add_conditional_edges(
        "intent_router",
        route_intent,
        {
            "clarification": "clarification",
            "finance_qa": "finance_qa",
            "portfolio_analysis": "portfolio_analysis",
            "market_analysis": "market_analysis",
            "goal_planning": "goal_planning",
            "news_synthesis": "news_synthesis",
            "tax_education": "tax_education",
            "multi_agent": "multi_agent",
            "error_handler": "error_handler"
        }
    )
    
    # All agent nodes route to response formatter
    agent_nodes = [
        "finance_qa", "portfolio_analysis", "market_analysis",
        "goal_planning", "news_synthesis", "tax_education", "multi_agent"
    ]
    
    for node in agent_nodes:
        graph.add_edge(node, "format_response")
    
    # Clarification re-routes
    graph.add_edge("clarification", "intent_router")
    
    # Response formatter ends
    graph.add_edge("format_response", END)
    
    # Error handler ends
    graph.add_edge("error_handler", END)
    
    return graph.compile()
```

## Key Features

### 1. Context Management
- Maintains full conversation history
- Updates user profile based on queries
- Tracks portfolio data across sessions
- Preserves user preferences

### 2. Error Handling & Fallbacks
- Market data unavailable → Use cached data + disclaimer
- API failures → Fallback to educational content
- Missing portfolio data → Request from user
- Low intent confidence → Ask clarifying questions

### 3. Multi-Agent Orchestration
- Parallel execution for independent agents
- Sequential execution for dependent agents
- Conflict resolution when agents disagree
- Result synthesis and coherence checking

### 4. Response Quality
- Citations and source attribution
- Complexity-adjusted explanations
- Risk disclaimers where appropriate
- Actionable recommendations

## Example Execution Flow: Portfolio Rebalancing Query

**User Query:** "My portfolio is heavy in tech stocks. Should I rebalance? What's the market outlook?"

**Execution Path:**
1. **Intent Router**: Detects "portfolio_analysis" + "market_info" (multi-agent)
2. **Multi-Agent Coordinator** (parallel execution):
   - **Portfolio Agent**: Analyzes current allocation, identifies concentration risk
   - **Market Agent**: Fetches tech sector data, assesses volatility
   - **Goal Planning Agent**: Reviews user's goals against current allocation
3. **Result Synthesis**: Combines recommendations
4. **Response Formatter**: Creates coherent response with:
   - Current allocation analysis
   - Concentration risk assessment
   - Market outlook
   - Rebalancing recommendations
   - Timeline suggestions
   - Tax implications
5. **Follow-ups**: "Would you like specific sector recommendations? Tax-loss harvesting strategies?"
