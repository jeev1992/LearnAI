# Call Center Summarization App - Multi-Agent LangGraph Architecture

## Project Overview

**Project Name:** Intelligent Call Processing & Quality Assurance System

**Description:** An intelligent multi-agent system that converts raw call data (audio or transcripts) into structured summaries and quality assurance insights. The system addresses the challenge of extracting crucial insights from long call transcripts and enables QA monitoring at scale through automated insight extraction and rubric-based evaluation.

**Key Objectives:**
- Process audio files (Whisper/Deepgram API integration)
- Generate structured call summaries with key points
- Evaluate quality using predefined QA rubrics
- Score agent performance (professionalism, tone, resolution)
- Extract compliance-relevant information
- Tag and highlight critical moments
- Support batch processing for multiple calls
- Provide actionable insights for training and improvement

## Agent Specifications

### Agent 1: Call Intake Agent
**Purpose:** Validates input formats, extracts metadata, and prepares call data for processing.

**Inputs:**
- Audio file (MP3, WAV, M4A) OR transcript text
- Call metadata (date, agent ID, customer ID, reason)
- Processing preferences
- Quality rubric version

**Outputs:**
- Validated file path/content
- Extracted metadata
- Call information summary
- Processing pipeline configuration
- Validation status

**Behavior:**
- Validates file format and integrity
- Extracts call metadata from filename or headers
- Determines processing flow (audio → transcription or text → summarization)
- Flags missing critical information
- Sets up processing parameters
- Ensures compliance with data retention policies

**Example Validation:**

### Agent 4: Quality Scoring Agent
**Purpose:** Evaluates call quality using predefined rubrics and provides actionable metrics.

**Inputs:**
- Call transcript
- Agent information
- QA rubric (scoring criteria)
- Quality standards/benchmarks
- Industry compliance requirements

**Outputs:**
- Quality scores (per metric)
- Overall quality score
- Strengths identified
- Improvement areas
- Compliance assessment
- Training recommendations
- Comparative metrics vs. team average

**Behavior:**
- Evaluates tone (professional, empathetic, patient)
- Assesses professionalism (language, courtesy)
- Checks problem resolution quality
- Validates procedure adherence
- Identifies training needs
- Compares against team benchmarks
- Generates actionable feedback

**QA Rubric Categories:**

**1. Professionalism (0-100)**
- Courteous language usage
- Absence of unprofessional language
- Appropriate greeting/closing
- Consistency throughout call

**2. Customer Tone Management (0-100)**
- Empathetic responses to complaints
- Patient handling of frustrated customers
- De-escalation effectiveness
- Active listening indicators

**3. Issue Resolution (0-100)**
- Problem clearly understood
- Appropriate solution offered
- Issue fully resolved
- Customer satisfaction indicated

**4. Procedure Adherence (0-100)**
- Required scripts/procedures followed
- Compliance with policies
- Data handling security
- Documentation completeness

**5. Communication Quality (0-100)**
- Clear explanations
- Jargon minimization
- Question handling
- Instruction clarity

**Overall Score Calculation:**
```
Overall = (Professionalism * 0.25) + 
          (Tone Management * 0.25) +
          (Resolution * 0.30) +
          (Procedure * 0.15) +
          (Communication * 0.05)
```

```python
from typing import TypedDict, Optional, List, Dict, Any
from datetime import datetime

class CallMetadata(TypedDict):
    """Call information and context"""
    call_id: str
    call_date: datetime
    agent_id: str
    customer_id: str
    call_reason: str
    duration_seconds: int
    channel: str  # "phone", "voip", etc.

class TranscriptSegment(TypedDict):
    """Individual speaker turn in transcript"""
    speaker: str  # "agent" or "customer"
    start_time: str
    end_time: str
    text: str
    confidence: float

class SummaryData(TypedDict):
    """Call summary information"""
    executive_summary: str
    key_points: List[str]
    customer_issue: str
    resolution: str
    follow_up_required: bool
    action_items: List[str]

class QAMetrics(TypedDict):
    """Quality assurance scores"""
    overall_score: float
    professionalism: float
    tone_management: float
    issue_resolution: float
    procedure_adherence: float
    communication_quality: float

class CallSummarizationState(TypedDict):
    """Complete state for Call Center Summarization LangGraph"""
    # Input
    input_file_path: Optional[str]
    input_transcript_text: Optional[str]
    input_type: str  # "audio" or "text"
    call_id: str
    session_id: str
    
    # Call Metadata
    call_metadata: CallMetadata
    
    # Processing
    validation_status: str  # "valid", "invalid", "pending"
    validation_errors: List[str]
    
    # Transcription (if audio input)
    transcript_text: Optional[str]
    transcript_segments: List[TranscriptSegment]
    transcription_confidence: float
    transcription_quality: Dict[str, Any]
    transcription_timestamp: Optional[datetime]
    
    # Summarization
    summary_data: Optional[SummaryData]
    sentiment_analysis: Dict[str, str]
    critical_moments: List[Dict[str, Any]]
    
    # Quality Assessment
    qa_metrics: Optional[QAMetrics]
    qa_strengths: List[str]
    qa_improvements: List[str]
    compliance_status: str  # "compliant", "flagged", "critical"
    training_recommendations: List[str]
    
    # Routing
    requires_manual_review: bool
    escalation_level: str  # "none", "moderate", "high"
    follow_up_required: bool
    
    # Batch Processing
    batch_id: Optional[str]
    batch_position: Optional[int]
    total_in_batch: Optional[int]
    
    # Final Output
    final_report: Dict[str, Any]
    formatted_output: str  # HTML or JSON string
    
    # Metadata
    execution_path: List[str]
    error_messages: List[str]
    fallback_triggered: bool
    processing_time_seconds: float
    total_tokens_used: int
```

```python
def input_intake(state: CallSummarizationState) -> CallSummarizationState:
    """
    Validates input and extracts metadata
    """
    # Validate file or text input
    # Extract call metadata
    # Determine processing flow
    
    if state['input_file_path']:
        validation = validate_audio_file(state['input_file_path'])
        state['input_type'] = 'audio'
    else:
        validation = validate_transcript_text(state['input_transcript_text'])
        state['input_type'] = 'text'
    
    state['validation_status'] = validation['status']
    state['validation_errors'] = validation.get('errors', [])
    state['call_metadata'] = extract_metadata(state['input_file_path'] or state['call_id'])
    state['execution_path'].append('input_intake')
    return state
```

#### Node 2: Transcription Agent
```python
def transcription_agent(state: CallSummarizationState) -> CallSummarizationState:
    """
    Converts audio to text using Whisper/Deepgram
    """
    if state['input_type'] != 'audio':
        state['transcript_text'] = state['input_transcript_text']
        state['transcription_confidence'] = 1.0
        state['execution_path'].append('transcription_agent_skipped')
        return state
    
    # Perform transcription
    result = transcribe_audio(
        file_path=state['input_file_path'],
        enable_diarization=True,
        language='en'
    )
    
    state['transcript_text'] = result['full_transcript']
    state['transcript_segments'] = result['segments']
    state['transcription_confidence'] = result['overall_confidence']
    state['transcription_quality'] = result['quality_metrics']
    state['transcription_timestamp'] = datetime.now()
    state['execution_path'].append('transcription_agent')
    
    return state
```

**Transitions:**
- SUCCESS → summarization_agent
- QUALITY_ISSUE → manual_review_flag
- API_ERROR → transcription_fallback

```python
def quality_scoring_agent(state: CallSummarizationState) -> CallSummarizationState:
    """
    Evaluates call quality using QA rubric
    """
    qa_result = score_call_quality(
        transcript=state['transcript_text'],
        segments=state['transcript_segments'],
        agent_id=state['call_metadata']['agent_id'],
        rubric_version='v2'  # Current rubric version
    )
    
    state['qa_metrics'] = qa_result['metrics']
    state['qa_strengths'] = qa_result['strengths']
    state['qa_improvements'] = qa_result['improvements']
    state['compliance_status'] = qa_result['compliance']
    state['training_recommendations'] = qa_result['training_recommendations']
    
    # Determine if manual review needed
    if qa_result['metrics']['overall_score'] < 60:
        state['requires_manual_review'] = True
        state['escalation_level'] = 'high'
    elif qa_result['compliance'] == 'flagged':
        state['requires_manual_review'] = True
        state['escalation_level'] = 'moderate'
    
    state['execution_path'].append('quality_scoring_agent')
    return state
```

**Transitions:**

#### Node 7: Error Handler
```python
def error_handler(state: CallSummarizationState) -> CallSummarizationState:
    """
    Handles invalid input and unrecoverable processing failures
    """
    state['error_messages'].extend(state['validation_errors'])
    state['fallback_triggered'] = True
    state['formatted_output'] = format_as_json({
        'status': 'error',
        'call_id': state['call_id'],
        'errors': state['error_messages'] or ['Unable to process call input']
    })
    state['execution_path'].append('error_handler')
    return state
```

**Transitions:**
- END → return to UI with error state

## State Transitions Code

```python
from langgraph.graph import StateGraph, END
from datetime import datetime

def create_call_summarization_graph():
    graph = StateGraph(CallSummarizationState)
    
    # Add nodes
    graph.add_node("input_intake", input_intake)
    graph.add_node("transcription", transcription_agent)
    graph.add_node("summarization", summarization_agent)
    graph.add_node("quality_scoring", quality_scoring_agent)
    graph.add_node("escalation", escalation_handler)
    graph.add_node("format_response", format_response)
    graph.add_node("error_handler", error_handler)
    
    # Set entry point
    graph.set_entry_point("input_intake")
    
    # Input intake validation routing
    def route_intake(state: CallSummarizationState) -> str:
        if state['validation_status'] != 'valid':
            return 'error_handler'
        
        if state['input_type'] == 'audio':
            return 'transcription'
        else:
            return 'summarization'
    
    graph.add_conditional_edges(
        "input_intake",
        route_intake,
        {
            "transcription": "transcription",
            "summarization": "summarization",
            "error_handler": "error_handler"
        }
    )
    
    # Transcription routing
    graph.add_edge("transcription", "summarization")
    
    # Summarization routing
    graph.add_edge("summarization", "quality_scoring")
    
    # Quality scoring routing
    def route_quality(state: CallSummarizationState) -> str:
        if state['requires_manual_review'] or state['escalation_level'] != 'none':
            return 'escalation'
        else:
            return 'format_response'
    
    graph.add_conditional_edges(
        "quality_scoring",
        route_quality,
        {
            "escalation": "escalation",
            "format_response": "format_response"
        }
    )
    
    # Escalation routes to format response
    graph.add_edge("escalation", "format_response")
    
    # Format response ends
    graph.add_edge("format_response", END)
    graph.add_edge("error_handler", END)
    
    return graph.compile()
```
